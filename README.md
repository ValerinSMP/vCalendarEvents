# vCalendarEvents

Proyecto para un sistema de calendario y eventos automáticos de ValerinSMP con notificaciones mediante webhook de Discord.

## Estado actual

Este repositorio todavía no contiene código fuente, descriptor de plugin ni configuración de build. Por tanto, no genera un JAR y no está listo para instalarse en Paper.

## Alcance previsto

- Calendario de eventos automáticos.
- Programación de inicio y cierre.
- Avisos a Discord mediante webhook.

La API, los comandos, la persistencia y la versión inicial deben definirse cuando comience la implementación.
