**vCalendarEvents** es el repositorio reservado para el futuro calendario de
eventos automáticos de ValerinSMP y sus notificaciones mediante Discord.

## 🚧 Estado actual

El proyecto todavía no contiene código fuente, descriptor de plugin ni build. No
genera un JAR y no está listo para instalarse en Paper.

## ⭐ Alcance previsto

- **⭐ Calendario automático** — Programación de eventos recurrentes.
- **⭐ Ciclo completo** — Inicio, cierre y estado visible de cada evento.
- **⭐ Avisos externos** — Notificaciones mediante webhook de Discord.

La API, los comandos, la persistencia, el prefijo y la versión inicial se definirán
cuando comience la implementación.
